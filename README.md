# Registro de Matriculados

Esta aplicación fue creada para ayudarme a llevar un control detallado de los clientes que se matriculan a través mío. Permite registrar cursos vendidos, calcular y acumular comisiones, anotar pagos recibidos, retiros realizados y mantener un seguimiento del saldo pendiente de cada persona.

## Características
- Registro de clientes
- Agregar cursos
- Registrar comisiones manualmente
- Cargar pagos recibidos
- Registrar retiros
- Visualización del saldo pendiente

## Tecnologías usadas
- React
- Tailwind CSS
- Vite
